# اشتراک موقت اپ برای بازبینی مدیران (بدون VPS)

وقتی می‌خواهی مدیرانِ **راه دور** اپ را ببینند ولی هنوز VPS نداری، این روش یک
**لینک عمومی HTTPS موقت** می‌سازد. روی شبکه‌های فیلترشده (که تونل Cloudflare بلاک
است) هم کار می‌کند، چون از **SSH** استفاده می‌کند.

---

## چطور اجرا کنم؟ (یک دستور)
در PowerShell، در پوشهٔ پروژه:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\share-for-review.ps1
```

- چند ثانیه صبر کن تا یک خط مثل این چاپ شود:
  `Forwarding HTTP traffic from https://xxxxxxxx.serveousercontent.com`
- آن آدرس را **به‌همراه `/senaite/`** برای مدیران بفرست. مثال:
  `https://xxxxxxxx.serveousercontent.com/senaite/`
- **این پنجره را باز نگه دار** تا وقتی مدیران کار دارند. با **Ctrl+C** اشتراک قطع می‌شود.

> بار اول ممکن است serveo یک صفحهٔ هشدار نشان دهد → مدیران روی **Continue** بزنند.

---

## چطور کار می‌کند؟ (که یاد بگیری) 📚

سه حلقه پشت سر هم:

```
مرورگر مدیر  →  serveo.net (اینترنت، HTTPS)  →  Caddy (روی کامپیوتر تو)  →  SENAITE :8080
```

1. **serveo.net** — یک سرور عمومی که با **SSH** به کامپیوتر تو وصل می‌شود و یک
   آدرس HTTPS می‌دهد. چون SSH است، فیلترِ DNS که جلوی Cloudflare را گرفته بود،
   این را نمی‌گیرد.
2. **Caddy** — یک پروکسی کوچک که یک مشکل مهم را حل می‌کند: SENAITE لینک‌ها را
   «مطلق» می‌سازد و بدون این پروکسی، لینک‌ها `http://` می‌شدند و مرورگر CSS/JS را
   بلاک می‌کرد (اپ بی‌استایل). Caddy با ترفند **VirtualHost** زوپ به SENAITE
   می‌گوید «تو https هستی»، پس همهٔ لینک‌ها درست `https://` می‌شوند.
3. **SENAITE** — همان اپ روی پورت 8080.

### چرا Cloudflare نشد ولی این شد؟
شبکهٔ شما آدرس سرورهای Cloudflare را به یک IP داخلی جعلی هدایت می‌کرد
(DNS hijacking). serveo از مسیر SSH می‌رود که آن فیلتر رویش اعمال نمی‌شود.

---

## محدودیت‌ها (مهم)
- **موقتی است:** هر بار که اسکریپت را اجرا کنی، **آدرس عوض می‌شود**. برای آدرس
  ثابت و همیشگی، همان **VPS + دامنه** راه درست است.
- تا وقتی پنجره باز است و کامپیوتر روشن/بیدار است کار می‌کند.
- serveo رایگان است و ممکن است گاهی کند یا موقتاً قطع شود؛ برای تحویل نهایی به
  مشتری از VPS استفاده کن.

---

## ربطش به VPS
همین **Caddyfile** (فایل `scripts/Caddyfile`) و همین ترفند VirtualHost، روی VPS
هم دقیقاً استفاده می‌شود — فقط به‌جای serveo، یک دامنهٔ واقعی و گواهی HTTPS دائمی
می‌گذاریم. پس این کار برای VPS هم **هدر نمی‌رود**.

## قطع کردن اشتراک
در همان پنجره **Ctrl+C** بزن (اسکریپت خودش Caddy را هم متوقف می‌کند).
اگر جایی گیر کرد، دستی:
```powershell
docker rm -f tandis-caddy
```
