۲) ورود به سیستم

  1. بروید به https://lims.tppc.ir/login
  2. نام کاربری و رمز خود را وارد کنید (رمز را مدیر داده است).
  3. منوی بالای صفحه: Samples، Clients، Worksheets، Batches و آیکون چرخ‌دنده (Setup).

۳) گردش کار کامل یک نمونه (هستهٔ آزمایشگاه)

ثبت (Register) → دریافت (Receive) → آزمون و ثبت نتیجه (Submit) → تأیید (Verify) → انتشار (Publish)

مهم: هر نمونه باید به یک «مشتری (Client)» وصل باشد؛ بدون مشتری نمی‌توان نمونه ثبت کرد. اگر مشتری ندارید، اول او را بسازید.
نکتهٔ کاربردی: در جریان واقعی معمولاً لازم نیست دستی مشتری بسازید — وقتی مشتری فرم آنلاین «درخواست آزمون» را پر می‌کند و پذیرش «تبدیل به نمونه» را می‌زند، سیستم خودش مشتری را می‌سازد (بخش ۵). ساخت دستی فقط برای مشتری حضوری/تلفنی است.

۳-۱) گام اول (الزامی): ساخت مشتری (Client)

اگر مشتری از قبل هست، این گام را رد کنید.

  1. بروید به https://lims.tppc.ir/clients
  2. دکمهٔ سبز Add بالای فهرست را بزنید.
  3. نام مشتری / شرکت را وارد کنید (بقیه اختیاری) → Save.
  4. (توصیه) داخل همان مشتری، بخش Contacts → Add → نام و ایمیل فرد تماس → Save (کسی که گزارش برایش می‌رود).

۳-۲) ثبت نمونهٔ جدید (پذیرش)

راه ساده‌تر — از داخل مشتری:

  1. بروید به https://lims.tppc.ir/clients و روی نام مشتری کلیک کنید.
  2. دکمهٔ Add را بزنید (فیلد Client از قبل پر است).

یا از فهرست نمونه‌ها:

  1. بروید به https://lims.tppc.ir/samples و دکمهٔ سبز Add را بزنید.
  2. در فرم، Client را از فهرست انتخاب کنید (باید از قبل ساخته شده باشد).

سپس (در هر دو راه):

  1. Contact، Date Sampled و Sample Type را پر کنید.
  2. آزمون‌های موردنیاز را تیک بزنید (فقط آزمون‌های فعال دیده می‌شوند).
  3. Save بزنید. نمونه با یک شناسهٔ یکتا ثبت می‌شود.

۳-۳) دریافت نمونه (Receive)

  1. در فهرست Samples نمونه را تیک بزنید.
  2. Receive بزنید (نمونهٔ فیزیکی رسیده و آماده آزمون است).

۳-۴) ثبت نتیجه (کارشناس آزمون)

  1. روی شناسهٔ نمونه کلیک کنید.
  2. مقابل هر آزمون نتیجه را وارد کنید.
  3. Submit بزنید.
نکتهٔ ۱۷۰۲۵: کسی که نتیجه را Submit کرده نمی‌تواند خودش آن را Verify کند.

۳-۵) تأیید نتیجه (تأییدکننده — فرد دوم)

  1. نمونه را باز کنید یا از فهرست تیک بزنید.
  2. نتیجه‌ها را کنترل و Verify بزنید.

۳-۶) انتشار گزارش (Publish)

  1. نمونهٔ تأییدشده را تیک بزنید.
  2. Publish بزنید → گزارش PDF ساخته می‌شود.
  3. می‌توانید همان‌جا برای ایمیل مشتری بفرستید (اگر SMTP تنظیم باشد).

۴) امور مشتریان (شکایت / نظرسنجی / پشتیبانی)

مشتری از کجا ثبت می‌کند؟

بدون ورود: https://lims.tppc.ir/@@customer-feedback — فرم را پر می‌کند و کد پیگیری + لینک می‌گیرد.

کارمند از کجا پاسخ می‌دهد؟

  1. آیکون چرخ‌دنده (Setup) را بزنید → کاشی «امور مشتریان» را کلیک کنید. (میان‌بر: https://lims.tppc.ir/setup/customercare)
  2. روی درخواست کلیک کنید.
  3. پاسخ را در «Response to customer» بنویسید.
  4. وضعیت را جلو ببرید: Process → Resolve → Close.
  5. هنگام Close، اگر مشتری ایمیل داده باشد، سیستم خودکار پاسخ + لینک را ایمیل می‌کند.
  6. برای ارسال دستی، لینک را از ستون «لینک مشتری» کپی کنید.

۵) پذیرش نمونهٔ آنلاین (درخواست آزمون → تبدیل به نمونه)

مشتری از کجا درخواست می‌دهد؟

بدون ورود: https://lims.tppc.ir/@@sample-request — آزمون‌ها را از فهرست انتخاب می‌کند (با ASTM)، کد + لینک می‌گیرد، سپس نمونه را می‌فرستد.

کارمند از کجا تبدیل می‌کند؟

  1. آیکون چرخ‌دنده (Setup) را بزنید → کاشی «پذیرش نمونه» را کلیک کنید. (میان‌بر: https://lims.tppc.ir/setup/sampleintake)
  2. روی درخواست کلیک کنید.
  3. دکمهٔ «تبدیل به نمونه» را بزنید.
  4. مشتری، نوع نمونه و آزمون‌ها را تأیید کنید (آزمون‌های خواسته‌شده از قبل تیک خورده‌اند) و تاریخ نمونه‌برداری را بگذارید.
  5. «ساخت نمونه» را بزنید → یک Sample واقعی ساخته می‌شود؛ از بخش ۳ ادامه دهید.

۶) مدیریت آزمون‌ها (مدیر)

مسیر: https://lims.tppc.ir/bika_setup/bika_analysisservices

فعال/غیرفعال کردن آزمون

  • آزمونی که دستگاهش را ندارید: تیک بزنید → Deactivate (دیگر در فرم‌ها دیده نمی‌شود).
  • بعد از خرید دستگاه: فیلتر را روی Inactive بگذارید → تیک بزنید → Activate.

افزودن ASTM یا قیمت

  1. روی آزمون کلیک کنید → Edit.
  2. ASTM را در نام اضافه کنید، مثل: عدد اسیدی کل (ASTM D664)
  3. Price را برای فاکتور وارد کنید.
  4. Save.
ASTM هرجا در نام آزمون باشد، خودکار در فرم مشتری و گزارش‌ها نمایش داده می‌شود.

۷) تنظیمات مدیریتی (فقط مدیر)

کاربران و نقش‌ها

https://lims.tppc.ir/@@usergroup-userprefs — Add User → نام کاربری، ایمیل، رمز قوی، انتخاب گروه/نقش. تغییر رمز/نقش از همین‌جا.

ایمیل خروجی (SMTP)

https://lims.tppc.ir/@@mail-controlpanel — SMTP server، Port ۵۸۷، Username، Password، From address → Save → Send test e-mail. جزئیات در EMAIL_SETUP.md.

۸) بک‌آپ و بازیابی

  • بک‌آپ دستی (روی سرور، PowerShell): powershell -ExecutionPolicy Bypass -File scripts\backup.ps1
  • بک‌آپ خودکار روزانه و بازیابی اضطراری: طبق GO_LIVE_CHECKLIST.md.

۹) پرسش‌های رایج

مشکلراه‌حل
نمی‌توانم نتیجهٔ خودم را تأیید کنمدرست است؛ تأیید باید توسط فرد دیگری باشد.
آزمونی در فهرست نیستاحتمالاً غیرفعال است؛ مدیر آن را Activate کند (بخش ۶).
مشتری می‌گوید ایمیل/لینک نرسیدایمیل مشتری در فرم؟ تنظیم SMTP؟ پوشهٔ Spam مشتری؟
همکاران وصل نمی‌شوندمطمئن شوید اینترنت وصل است و آدرس https://lims.tppc.ir را می‌زنند. سامانه روی اینترنت است؛ نیازی به شبکهٔ داخلی نیست.
رمزم را فراموش کردممدیر از بخش ۷ رمز جدید بگذارد.
