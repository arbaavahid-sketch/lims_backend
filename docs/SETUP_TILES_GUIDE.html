راهنمای «تنظیمات سامانه»

سامانهٔ مدیریت آزمایشگاه تندیس (LIMS) — هر کاشی چیست و به چه کار می‌آید

صفحهٔ «تنظیمات سامانه» جایی است که ساختار و دادهٔ پایهٔ آزمایشگاه تعریف می‌شود؛ یعنی «مغز» سیستم. بقیهٔ بخش‌ها (پذیرش نمونه، ثبت نتیجه، گزارش‌گیری) از همین داده‌ها استفاده می‌کنند. این راهنما هر ۴۲ کاشی را به‌زبان ساده معرفی می‌کند. رنگ حاشیهٔ هر کارت نشان می‌دهد به کدام گروه تعلق دارد.

قلب آزمایشگاه چه چیزی را آزمایش می‌کنیم

سرویس‌های آنالیز ۱۸۱ مورد

Analysis Services

مهم‌ترین بخش سامانه. فهرست کامل تمام آزمون‌هایی که آزمایشگاه انجام می‌دهد — مانند گرانروی، نقطه اشتعال، خاکستر سولفاته، عدد اسیدی — همراه با استاندارد ASTM، واحد اندازه‌گیری، روش انجام، قیمت و حدود مجاز.

کجا استفاده می‌شود؟ هر آزمونی که روی نمونه ثبت می‌کنید و هر برگهٔ نتیجه‌ای که صادر می‌شود، از این فهرست می‌آید. همان چک‌باکس‌هایی که مشتری در فرم درخواست می‌بیند.

دسته‌های آنالیز ۶ مورد

Analysis Categories

آزمون‌ها را در ۶ دستهٔ اصلی آزمایشگاه گروه‌بندی می‌کند: روغن، نفت خام، قیر، گریس، هیدروکربن و ضدیخ.

کجا استفاده می‌شود؟ برای مرتب‌کردن آزمون‌ها در فرم‌ها و گزارش‌ها؛ همین دسته‌ها چک‌باکس‌های فرم مشتری را گروه‌بندی می‌کنند.

زیرگروه‌ها

Sub-groups

تقسیم‌بندی ریزتر داخل یک دسته (مثلاً «فلزات سنگین» یا «خواص فیزیکی» درون یک دسته).

کجا استفاده می‌شود؟ برای چیدمان مرتب‌تر نتایج مرتبط، کنار هم در گزارش.

دپارتمان‌های آزمایشگاه ۶ مورد

Lab Departments

بخش‌های فیزیکی/سازمانی آزمایشگاه. هر آزمون به یک دپارتمان مسئول وصل می‌شود.

کجا استفاده می‌شود؟ برای مشخص‌کردن مسئولیت هر بخش و گرفتن آمار عملکرد به‌تفکیک دپارتمان.

نمونه‌ها نمونه چه شکلی است

انواع نمونه ۱۱۴ مورد

Sample Types

نوع مادهٔ ارسالی مشتری: روغن موتور، نفت خام، قیر، گازوئیل، ضدیخ و… .

کجا استفاده می‌شود؟ هنگام پذیرش نمونه، اول نوع نمونه انتخاب می‌شود تا آزمون‌های مرتبط پیشنهاد شوند.

انواع ظرف

Container Types

نوع ظرفی که نمونه در آن می‌آید (بطری شیشه‌ای، بشکه، ظرف پلاستیکی) و حجم آن.

کجا استفاده می‌شود؟ برای ثبت و ردیابی فیزیکی نمونه در انبار.

ظرف‌های نمونه

Sample Containers

ظرف‌های مشخص و موجودِ آزمایشگاه (بر پایهٔ «انواع ظرف») که به نمونه اختصاص داده می‌شوند.

کجا استفاده می‌شود؟ مدیریت موجودی ظروف و تخصیص آن‌ها به نمونه‌ها.

انحرافات نمونه‌گیری

Sampling Deviations

ثبت این‌که نمونه‌گیری خارج از شرایط استاندارد انجام شده (مثلاً دمای نامناسب، تأخیر).

کجا استفاده می‌شود؟ برای شفافیت و انطباق با ISO 17025 — هر انحراف مستند و قابل ردیابی می‌شود.

دستگاه‌ها و کیفیت با چه چیزی آزمایش می‌کنیم

تجهیزات ۳۰ مورد

Instruments

دستگاه‌های واقعی آزمایشگاه، هر کدام با شمارهٔ سریال، سازنده و تاریخ کالیبراسیون.

کجا استفاده می‌شود؟ داشبورد کالیبراسیون از این‌جا هشدار رنگی می‌دهد وقتی اعتبار کالیبراسیون یک دستگاه رو به پایان است.

انواع دستگاه ۲۸ مورد

Instrument Types

نوع/مدل کلی دستگاه‌ها (مثلاً «ICP»، «ویسکومتر»، «دستگاه نقطه اشتعال»).

کجا استفاده می‌شود؟ دسته‌بندی تجهیزات و ربط‌دادن هر آزمون به نوع دستگاه مناسب.

تولیدکنندگان ۱۵ مورد

Manufacturers

شرکت‌های سازندهٔ دستگاه‌ها (کارخانهٔ سازنده).

کجا استفاده می‌شود؟ در مشخصات هر دستگاه، برای پیگیری خدمات و قطعات.

تعاریف مرجع

Reference Definitions

مواد مرجع و نمونه‌های استاندارد کنترل کیفیت با مقادیر شناخته‌شده.

کجا استفاده می‌شود؟ برای صحت‌سنجی دستگاه‌ها و آزمون‌ها (کنترل کیفیت داخلی) — بخش مهم ISO 17025.

تأمین‌کنندگان

Suppliers

شرکت‌هایی که مواد مرجع، استانداردها یا خدمات کالیبراسیون را تأمین می‌کنند.

کجا استفاده می‌شود؟ در تعاریف مرجع و کالیبراسیون، برای مشخص‌کردن منبع تأمین.

اسناد و مشتری ارتباط با بیرون و مستندسازی

امور مشتریان ۳ مورد

Customer Care

بخش خدمات مشتری: شکایت‌ها، نظرسنجی‌ها و درخواست‌های پشتیبانی که مشتری از فرم آنلاین ثبت می‌کند. عدد «۳» یعنی هم‌اکنون سه درخواست ثبت شده است.

کجا استفاده می‌شود؟ کارمند این‌جا درخواست را می‌بیند، پاسخ می‌دهد و «می‌بندد» — با بستن، ایمیل پاسخ به‌صورت خودکار برای مشتری ارسال می‌شود.

اسناد کنترل‌شده

Controlled Documents

روش‌های اجرایی و دستورالعمل‌ها (SOP) با نسخه‌بندی و گردش تأیید (پیش‌نویس ← تأیید ← معتبر ← بازنگری/ابطال).

کجا استفاده می‌شود؟ برای مدیریت مستندات کیفیت و آمادگی برای ممیزی ISO 17025.

برچسب‌ها

Labels

برچسب‌های دلخواه برای دسته‌بندی و فیلترکردن نمونه‌ها و رکوردها.

کجا استفاده می‌شود؟ برای پیداکردن سریع گروهی از نمونه‌ها (مثلاً یک پروژهٔ خاص).

برچسب‌های بچ

Batch Labels

برچسب مخصوص «بچ» (مجموعه‌ای از نمونه‌های مرتبط که با هم پردازش می‌شوند).

کجا استفاده می‌شود؟ برای سازمان‌دهی و پیگیری بچ‌های کاری.

انواع پیوست

Attachment Types

نوع فایل‌های ضمیمه‌ای که به نمونه یا نتیجه می‌چسبد (کروماتوگرام، عکس، PDF گواهی).

کجا استفاده می‌شود؟ برای دسته‌بندی مستندات پیوستِ هر نمونه.

سیستم تنظیمات کلی

تنظیمات سامانه

Setup / Preferences

تنظیمات عمومی سیستم: قالب شماره‌گذاری نمونه‌ها، گردش کار، واحدها و رفتار کلی برنامه.

کجا استفاده می‌شود؟ پیکربندی یک‌بارهٔ کل سامانه توسط مدیر سیستم.

آزمایشگاه پتروشیمی تندیس پارس

Laboratory Information

مشخصات خودِ آزمایشگاه: نام، لوگو، آدرس، اطلاعات تماس و امضای مجاز.

کجا استفاده می‌شود؟ این اطلاعات در سربرگ و پاورقی گزارش‌ها و گواهی‌ها چاپ می‌شود.

قلب آزمایشگاه کیفیت، حدود مجاز و محاسبات

مشخصات آنالیز ۳۳ مورد

Analysis Specifications

حدود مجاز (کمینه/بیشینه) هر آزمون برای هر نوع نمونه.

کجا استفاده می‌شود؟ نتیجه‌ای که خارج از حد باشد را خودکار قرمز/مردود می‌کند (قبول یا رد آزمون).

مشخصات پویای آنالیز

Dynamic Analysis Specifications

حدود مجازی که ثابت نیستند و بر اساس شرایط (جدول اکسل‌مانند) تغییر می‌کنند.

کجا استفاده می‌شود؟ نسخهٔ پیشرفتهٔ «مشخصات آنالیز» برای وقتی حد مجاز به پارامترها بستگی دارد.

محاسبات ۱ مورد

Calculations

فرمول‌هایی که یک نتیجه را خودکار از روی نتایج دیگر حساب می‌کنند.

کجا استفاده می‌شود؟ برای آزمون‌های محاسباتی (مثلاً مقداری که از دو اندازه‌گیری دیگر به‌دست می‌آید).

پروفایل‌های آنالیز

Analysis Profiles

«پکیج» آزمون‌هایی که معمولاً با هم سفارش داده می‌شوند.

کجا استفاده می‌شود؟ با یک انتخاب، کل مجموعهٔ آزمون‌ها روی نمونه اضافه می‌شود (سرعت و قیمت‌گذاری).

اسناد و مشتری قالب‌ها (آماده‌سازی سریع)

قالب‌های نمونه

Sample Templates

مجموعهٔ آزمون‌های ازپیش‌تعریف‌شده برای یک نوع نمونهٔ رایج.

کجا استفاده می‌شود؟ هنگام پذیرش، با انتخاب قالب همهٔ آزمون‌های استاندارد آن نمونه یک‌جا اضافه می‌شوند.

قالب‌های کاربرگ

Worksheet Templates

چیدمان ازپیش‌آمادهٔ کاربرگ برای کارشناس (جای نمونه‌ها و نمونه‌های کنترلی).

کجا استفاده می‌شود؟ ساخت کاربرگ کاری را سریع و یک‌دست می‌کند.

قالب‌های تفسیر

Interpretation Templates

متن‌های آمادهٔ بخش «تفسیر/توضیح» گزارش.

کجا استفاده می‌شود؟ تا کارشناس مجبور نباشد هر بار توضیح گزارش را از نو بنویسد.

نمونه‌ها دادهٔ تکمیلی نمونه

ماتریکس‌های نمونه

Sample Matrices

بستر/محیط پایهٔ نمونه (آبی، روغنی، جامد…).

کجا استفاده می‌شود؟ دسته‌بندی انواع نمونه بر اساس ماهیت پایه.

نقاط نمونه‌گیری

Sample Points

نقاط مشخص برداشت نمونه (شیر، مخزن، خط تولید معیّن).

کجا استفاده می‌شود؟ ثبت اینکه نمونه دقیقاً از کجا برداشته شده است.

نگهداری‌های نمونه

Sample Preservations

روش‌های نگهداری نمونه (سرمایش، افزودنی شیمیایی).

کجا استفاده می‌شود؟ برای حفظ اعتبار نمونه تا زمان آزمایش.

وضعیت‌های نمونه

Sample Conditions

وضعیت نمونه هنگام دریافت (سالم، سرد، آسیب‌دیده، پلمب…).

کجا استفاده می‌شود؟ ثبت شرایط دریافت برای کیفیت و ISO.

محل‌های نگهداری

Storage Locations

جای فیزیکی انبار و نگهداری نمونه‌ها.

کجا استفاده می‌شود؟ برای پیداکردن سریع نمونه در انبار.

دستگاه‌ها و کیفیت تکمیلی

محل‌های دستگاه

Instrument Locations

محل فیزیکی استقرار هر دستگاه در آزمایشگاه.

کجا استفاده می‌شود؟ برای مدیریت و پیداکردن تجهیزات.

اسناد و مشتری افراد و مخاطبین

مخاطبین آزمایشگاه ۹ مورد

Lab Contacts

پرسنل خودِ آزمایشگاه (کارشناسان، امضاکنندگان) — مخاطبین داخلی.

کجا استفاده می‌شود؟ تعیین کارشناس/امضاکنندهٔ گزارش‌ها.

مخاطبین

Contacts

افراد رابط در شرکت‌های مشتری — مخاطبین بیرونی.

کجا استفاده می‌شود؟ برای ارتباط با مشتری و ارسال نتایج.

سیستم سایر و بخش‌های سفارشی

محصولات آزمایشگاهی

Lab Products

کالاها/خدمات قیمت‌دار آزمایشگاه.

کجا استفاده می‌شود؟ در صورتحساب و قیمت‌گذاری خدمات.

پذیرش نمونه (درخواست‌های آنلاین) سفارشی

Sample Intake

بخش سفارشیِ ما: درخواست‌های آزمونِ آنلاین که مشتری ثبت می‌کند.

کجا استفاده می‌شود؟ کارمند این درخواست‌ها را دیده و به نمونهٔ رسمی تبدیل می‌کند.

لاگ ممیزی

Audit Log

ثبت هر تغییر: چه کسی، چه چیزی را، چه زمانی عوض کرد.

کجا استفاده می‌شود؟ ستون اصلی ردیابی و ممیزی ISO 17025.

سیستم داشبوردها و گزارش‌های مدیریتی 📊

عملکرد آزمونگرها

Analysts Performance

داشبورد حجم کار و عملکرد هر کارشناس.

این‌ها دادهٔ پایه نیستند؛ گزارش/داشبورد مدیریتی‌اند که از داده‌های موجود ساخته می‌شوند.

وضعیت کالیبراسیون دستگاه‌ها

Instruments Calibration Status

Documents Review Status

داشبورد: کدام سند کنترل‌شده نیاز به بازنگری/تمدید دارد.

Customer Care Dashboard

داشبورد: وضعیت شکایت‌ها و درخواست‌های مشتری در یک نگاه.
