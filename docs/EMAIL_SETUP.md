# راه‌اندازی ایمیل (SMTP) — آزمایشگاه تندیس (TPPC)
# Email / SMTP Setup

این سند به شما می‌گوید **خودتان از کجا** ایمیل خروجی سیستم را تنظیم کنید.
پس از این تنظیم، سیستم می‌تواند گزارش‌ها و اعلان‌ها را ایمیل کند و در مرحلهٔ
بعد می‌توانیم ارسال خودکار **لینک جواب مشتری** را هم فعال کنیم.

> Set the outgoing mail server here yourself; the password stays with you.

---

## گام ۱ — رفتن به صفحهٔ تنظیمات ایمیل

با حساب `admin` وارد شوید و به این آدرس بروید:

```
http://localhost:8080/senaite/@@mail-controlpanel
```

(همین صفحه از مسیر منو هم در دسترس است: بالا سمت راست → **Site Setup / تنظیمات
سایت** → **Mail / ایمیل**.)

---

## گام ۲ — پر کردن فیلدها

| فیلد در فرم | چه بگذارید | مثال |
|---|---|---|
| **SMTP server** | آدرس سرور ایمیل | `mail.tandis.co` یا `smtp.gmail.com` |
| **SMTP port** | پورت | `587` (TLS) یا `465` (SSL) یا `25` |
| **ESMTP username** | نام کاربری ایمیل | `no-reply@tandis.co` |
| **ESMTP password** | رمز آن ایمیل | (رمز شما) |
| **From name** | نام فرستنده | `آزمایشگاه تندیس` |
| **From address** | ایمیل فرستنده | `no-reply@tandis.co` |

> این اطلاعات را از **میزبان ایمیل سازمان** (هاست/ISP) یا از تنظیمات ایمیل
> شرکتی خود می‌گیرید.

---

## گام ۳ — ذخیره و ارسال ایمیل آزمایشی

۱. **Save / ذخیره** را بزنید.
۲. در همان صفحه بخش **Send test e-mail** یک آدرس ایمیل خودتان وارد کنید و
   ارسال کنید.
۳. اگر ایمیل آزمایشی رسید، تنظیمات درست است. ✅

---

## نکات رایج (اگر ایمیل نرفت)

- **Gmail / Google Workspace:** رمز عادی کار نمی‌کند؛ باید **App Password**
  بسازید (نیازمند فعال بودن 2-Step Verification). پورت `587`.
- **پورت مسدود:** بعضی شبکه‌ها پورت `25` را می‌بندند؛ از `587` استفاده کنید.
- **گواهی TLS:** اگر سرور داخلی است و خطای گواهی داد، با میزبان ایمیل هماهنگ کنید.
- **پوشهٔ Spam:** ایمیل آزمایشی ممکن است به Spam برود؛ آنجا را هم چک کنید.
- **رکورد SPF/DKIM:** برای اینکه ایمیل‌ها به Inbox مشتری برسد (نه Spam)، از
  مدیر دامنه بخواهید SPF/DKIM ایمیل فرستنده را تنظیم کند.

---

## بعد از تنظیم SMTP چه چیزی فعال می‌شود؟

۱. **همین حالا:** ارسال گزارش نتایج به مشتری از خود SENAITE (Publish → Email).
۲. **مرحلهٔ بعد (فاز ۷):** پس از اینکه SMTP کار کرد، به من بگویید تا **ارسال
   خودکار لینک جواب امور مشتریان** را فعال کنم — یعنی وقتی کارمند به یک شکایت/
   درخواست پاسخ داد و آن را بست، سیستم خودش لینک اختصاصی جواب را برای مشتری
   ایمیل کند (به‌جای کپی دستی از ستون «لینک مشتری»).

> وقتی ایمیل آزمایشی با موفقیت رسید، فقط کافی است بگویید «SMTP آماده است» تا
> ارسال خودکار لینک را برایتان کدنویسی و فعال کنم.
