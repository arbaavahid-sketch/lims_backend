سناریوی تست کامل — دو‌نفره

آزمایشگاه تندیس (TPPC) — محک کل چرخه با دو کاربر واقعی
نفر A پذیرش + آنالیست — ساخت مشتری، ثبت نمونه، ثبت نتیجه
نفر B تأییدکننده + انتشار — کنترل، تأیید، صدور گزارش

آماده‌سازی

  1. هر دو نفر وارد شوند: http://192.168.1.33:8080/senaite/login
  2. اگر روی همین کامپیوترِ سرور کار می‌کنید، برای نفر دوم یک مرورگر InPrivate/جدا باز کنید تا دو حساب هم‌زمان باز باشند.

بخش ۱ — گردش نمونه (هستهٔ اصلی)

A ساخت مشتری

  1. نوار کناری → Clients → دکمهٔ سبز Add.
  2. نام: مثلاً «شرکت پتروشیمی نمونه» → Save.
  3. داخل همان مشتری → بخش Contacts → Add → نام «علی رضایی» + یک ایمیل واقعی خودت (برای تست گزارش) → Save.

A ثبت نمونه

  1. نوار کناری → Samples → Add (یا از داخل مشتری، Add).
  2. Client = همان مشتری، Contact = علی رضایی، Date Sampled = امروز، Sample Type = مثلاً «نفت خام».
  3. چند آزمون تیک بزن: مثلاً عدد اسیدی (ASTM D664) و گرانروی کینماتیک (ASTM D445).
  4. Save → یک شناسهٔ نمونه ساخته می‌شود؛ یادداشتش کن.

A دریافت و ثبت نتیجه

  1. نمونه را تیک بزن → Receive.
  2. روی شناسهٔ نمونه کلیک کن → مقابل هر آزمون یک عدد وارد کن (مثلاً 0.5 و 12.3).
  3. Submit بزن.

B تأیید — مهم‌ترین تست

  1. نفر B وارد شود → نوار کناری Samples → نمونه را باز کن.
  2. Verify بزن.
✅ کلیدی: نفر B می‌تواند تأیید کند چون نفر A نتیجه را ثبت کرده بود. اگر نفر A بخواهد خودش تأیید کند، سیستم نمی‌گذارد — و همین درست است (الزام ISO 17025).

B انتشار گزارش

  1. نمونهٔ تأییدشده را تیک بزن → Publish → گزارش PDF ساخته می‌شود.
  2. اگر خواستی، همان‌جا برای ایمیل مشتری بفرست → Inbox علی رضایی را چک کن.

بخش ۲ — حلقهٔ مشتری (فرم عمومی + لینک)

مشتری ثبت درخواست آزمون (بدون ورود)

  1. روی یک مرورگر InPrivate برو به http://192.168.1.33:8080/senaite/@@sample-request
  2. فرم را پر کن، ایمیل خودت را بگذار، چند آزمون از فهرست انتخاب کن (با ASTM) → Submit → یک کد پیگیری بگیر.

A تبدیل درخواست به نمونه

  1. نوار کناری → کاشی «پذیرش نمونه» → روی درخواست کلیک کن → «تبدیل به نمونه».
  2. مشتری/نوع نمونه را تأیید کن (آزمون‌های خواسته‌شده از قبل تیک خورده‌اند) → ساخت نمونه.
از اینجا مثل بخش ۱ ادامه می‌رود: دریافت → نتیجه (A) → تأیید (B) → انتشار (B).

مشتری ثبت شکایت + تست ایمیل خودکار

  1. مشتری برود به http://192.168.1.33:8080/senaite/@@customer-feedback → یک شکایت با ایمیل خودت ثبت کند.
  2. نفر A → کاشی «امور مشتریان» → درخواست را باز کن → پاسخ بنویس → Process → Resolve → Close.
  3. هنگام Close، به Inbox خودت نگاه کن → باید ایمیل پاسخ + لینک برسد. ✅

✔️ این تست چه چیزهایی را ثابت می‌کند

  • جداسازی آنالیست / تأییدکننده (ISO 17025)
  • گردش کامل نمونه از ثبت تا گزارش PDF
  • فرم عمومی + انتخاب آزمون از فهرست با ASTM
  • تبدیل درخواست آنلاین مشتری به نمونهٔ واقعی
  • ارسال خودکار ایمیل پاسخ + لینک به مشتری
  • کار هم‌زمان دو کاربر با نقش‌های مختلف
برای ذخیره به‌صورت PDF: در مرورگر Ctrl+P → مقصد را «Save as PDF». — راهنمای کامل کار با سامانه: USER_GUIDE.html.
